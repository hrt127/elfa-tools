# The Narrative OS Loop — Reasoning

The system answers one question:

> "Has something changed enough that a human should notice now?"

Everything else supports this.

---

## Core Principle

Silence is success. Interruptions must be earned.

The system prefers to miss marginal events rather than spam attention.

---

## Canonical Flow

```
observe → enrich → decide → gate → explain → interrupt (or not)
```

Each stage answers exactly one question:

| Stage | Question |
|-------|----------|
| Observe | What exists right now? |
| Enrich | How is it changing? |
| Decide | Is the change coherent? |
| Gate | Is this worth interruption? |
| Explain | Why did this survive the gate? |
| Interrupt | How does the human learn? |

No stage may answer a future stage's question.

---

## Why This Works

- **Separation of concerns** prevents accidental signals
- **Explainability by construction** prevents black boxes
- **Policy gating** protects human attention
- **Composable outputs** allow many surfaces without logic duplication

Elfa is not predictive. It is interpretive.

The human remains the decision-maker.
