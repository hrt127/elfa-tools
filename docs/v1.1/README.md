## MVP vs v1.1

**MVP Core** (in root directory):
- `elfa_client.py` - Fetch narrative data
- `narrative_enricher.py` - Add temporal context
- `narrative_radar.py` - View enriched data
- `decision_moment.py` - Core concept

**v1.1 Features** (in `optional/` directory):
- Multi-source signal fusion
- Rule-based alerting
- Historical analysis
- Trading workflows
- Advanced visualizations

See [../README.md](../README.md) for MVP quickstart.
